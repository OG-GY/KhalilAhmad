# Khalil Ahmad — Personal Portfolio

> Live at **[khalil-ahmad.vercel.app](https://khalil-ahmad.vercel.app)**

A production-grade personal portfolio built with Next.js and TypeScript. Features a services marketplace, 12 project showcases, speaking event history, community work timeline, and a working contact form — all statically generated and deployed on Vercel.

---

## What's Inside

- **Services** — Full-Stack, Frontend, UI/UX, Web Scraping with pricing and availability
- **Projects** — 12 live case studies with stack, screenshots, and impact
- **Speaking Events** — 5 technical sessions with attendee counts and event details
- **Experience** — Professional timeline with tech stack and key achievements per role
- **Community** — MLSA, Youth Empowerment, One-University contributions
- **Contact Form** — Project inquiry form with budget, timeline, and type fields

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 14 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS |
| Components | ShadCN UI, AnimataUI |
| Deployment | Vercel |

---

## Highlights

- Fully responsive — mobile, tablet, desktop
- Optimized images via `next/image`
- SEO metadata per page
- Services detail pages with dynamic routing
- Speaking events section with poster images and attendee stats
